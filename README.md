# Filming Schedule – LAB

The **test copy** of Filming Schedule, for trying new things (like the private AI reader) without touching the real app.

- Its own database (Firebase project `filming-schedule-lab`) – your real schedule is never changed from here.
- Its own website: https://cassiomariano.github.io/filming-schedule-lab/ (orange **LAB** tag).
- No phone alerts. Reads your inboxes only if you add the lab Yahoo secrets, and then read-only.
- The code lives in the private repository (branch `lab`), never here.
